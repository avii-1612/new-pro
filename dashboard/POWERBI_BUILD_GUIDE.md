# Power BI Dashboard: Build Guide

Quick note on the .pbix file: it's a proprietary binary that only Power BI Desktop can save, so it can't be generated by a script. This guide has everything you need to build it yourself in maybe 20-30 minutes: the data source, the DAX measures, and the layout. This is basically the same process a working analyst goes through anyway.

## 1. Data source
Import `data/cleaned/ecommerce_cleaned.csv` into Power BI Desktop (Get Data > Text/CSV). It already has the calculated columns (Revenue, Profit_Margin, Month, Quarter, Year), so there isn't much cleanup needed in Power Query. You can also pull in `data/cleaned/customer_segments.csv` and relate it to the main table on `Customer_ID` if you want the segment slicer to work.

## 2. DAX measures
Create these as new measures on the `ecommerce_cleaned` table (Modeling > New Measure):

```dax
Total Revenue = SUM(ecommerce_cleaned[Revenue])

Total Profit = SUM(ecommerce_cleaned[Profit])

Total Orders = DISTINCTCOUNT(ecommerce_cleaned[Order_ID])

Total Customers = DISTINCTCOUNT(ecommerce_cleaned[Customer_ID])

Average Order Value = DIVIDE([Total Revenue], [Total Orders])

Profit Margin % = DIVIDE([Total Profit], [Total Revenue], 0)

Revenue LY = CALCULATE([Total Revenue], SAMEPERIODLASTYEAR(ecommerce_cleaned[Order_Date]))

Revenue YoY % = DIVIDE([Total Revenue] - [Revenue LY], [Revenue LY])
```

One thing to remember: build an actual Date table (Modeling > New Table, then `CALENDAR(MIN(ecommerce_cleaned[Order_Date]), MAX(ecommerce_cleaned[Order_Date]))`) and mark it as the Date Table, otherwise `SAMEPERIODLASTYEAR` won't work right.

## 3. Layout

**KPI cards across the top:**
Total Revenue, Total Profit, Total Orders, Total Customers, Average Order Value, Profit Margin %

**Trend row:**
Line chart, Month on X, Total Revenue and Total Profit on Y

**Category/region row:**
- Bar chart: Category vs Total Revenue, sorted descending
- Bar chart: Category vs Total Profit
- Bar chart: Region vs Total Revenue

**Products/segments row:**
- Table or bar chart: top 10 products by revenue (use a Top N filter)
- Donut chart: customer segment breakdown, using `Segment` from customer_segments.csv

**Slicers:**
Date range, Region, Category, Customer_Type

## 4. Keeping it clean
This should look like a business dashboard, not a flashy portfolio piece:
- Stick to 2-3 colors max, one accent color for Revenue and another for Profit throughout
- No unnecessary borders or shadows on cards
- Align everything to a grid, keep margins consistent
- Use tooltips for extra detail rather than cramming more visuals in

## 5. How to talk about this in an interview
Something like: "I built the DAX measures and dashboard in Power BI on top of a cleaned CSV from my Python pipeline, with KPI cards up top, category and regional breakdowns below, and slicers so someone could filter by date, region, category, or customer type."
